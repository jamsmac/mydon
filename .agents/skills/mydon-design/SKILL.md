# /mydon-design — дизайн-система MYDON (толстый навык)

Этот файл — **роутер**. Не пересказывает содержимое референсов — говорит, что и когда читать.
Задача навыка: чтобы каждый новый экран выходил в системе MYDON за 1–2 итерации без объяснений заново.

## Порядок работы

1. **Прочитай `rules.md`** (всегда, 2 минуты) — правило оранжевого, три уровня текста, русский язык, «плитка = вопрос владельца».
2. **Прочитай `tokens.md`** — имена токенов и их роли. Новые токены **не заводить**; цвет вне палитры — только `--agent`.
3. **Прочитай `primitives.md`** — готовые классы из `apps/cc/src/app/globals.css`: страница, карточка, плитка, строка, чип, кнопка, пустое состояние, предупреждение. Собирай экран из них; новый класс — только если примитива нет, и тогда в `globals.css` рядом с родственными.
4. Посмотри **эталонные экраны** (по задаче, не все):
   - главная/виджеты — `apps/cc/src/app/mydon/page.tsx`
   - список агентов и карточка — `apps/cc/src/app/agents/page.tsx`, `apps/cc/src/app/agents/[name]/page.tsx`
   - навигация (сайдбар / таббар) — `apps/cc/src/components/nav.tsx`, `apps/cc/src/app/layout.tsx`
   - эталон мутирующей формы — `apps/cc/src/components/customs-rates.tsx` (+ `customs-rates.test.tsx`)
   - макеты Codex Design — `design/dashboard-redesign/{Main,Navigation,List,Service,Tasks}.dc.html`
5. Сверстай. Для страниц командного центра (`/mydon`, `/agents`, `/crons`, `/flows`, `/skills`, `/brain`,
   `/artifacts`) — консольная грамматика из `rules.md` §4 (тёмная тема по умолчанию, `.lbl`, LED-статусы, аватары).
6. **Пройди `checklist.md`** перед тем как показать результат. Пункты про контраст и сохранение ввода — не опциональны.

## Что навык НЕ делает

- Не меняет значения токенов и не добавляет цвета: палитра проверена расчётом контраста (числа — в комментариях `globals.css`).
- Не использует `next/font/google` (сборка не ходит в сеть — причина в `apps/cc/src/app/layout.tsx`).
- Не переводит подписи на латиницу (решение Р-2 от 22.08.2026).
- Не возвращает формы к `<form action={fn}>` (React 19 сбрасывает поля; конвенция от 24.08.2026 в `AGENTS.md`).
