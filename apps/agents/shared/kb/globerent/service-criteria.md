# Критерии сервиса GLOBERENT (для globerent-service)

> Рубрика классификации, приоритета и эскалации сервисных обращений по проданным HELI.
> Читается скиллами `triage-service` и `draft-service-reply`. Внешних данных не выдумывать.

## Классификация (тип обращения)
- **запчасть** — нужна деталь/расходник. (⚠ каталога запчастей с ценами/наличием в KB пока НЕТ — см. «Нужны данные».)
- **ТО** — плановое/внеплановое техобслуживание (масла, фильтры, регламент часов наработки).
- **гарантия** — отказ в гарантийный период; решение по гарантии — всегда человек.
- **ремонт** — неплановый отказ/поломка вне гарантии.

## Приоритет
- **🔴 высокий** — машина простаивает (клиент несёт убытки), гарантийный отказ ключевого клиента, безопасность.
- **🟡 средний** — машина работает, но с ограничением; приближается срок планового ТО.
- **⚪ низкий** — справочный запрос, плановое будущее ТО, некритичная запчасть.

Сигналы срочности из поля `urgency`/`description`: «стоит», «не заводится», «течёт», «простой», «срочно» → высокий.

## Маршрутизация / границы
- Коммерческое предложение на новую технику → это `globerent-sales` (`draft-quote`), не сервис.
- Тендеры/госзакупки → `market-analyst` (`scan-tenders`).
- Здесь — послепродажный сервис по УЖЕ проданным машинам.

## Эскалация человеку (всегда)
- Любое решение по гарантии (признать/отказать).
- Стоимость ремонта/запчасти, скидки, сроки-обязательства клиенту.
- Простой машины ключевого клиента (напр. крупная дебиторка — см. `clients.md`).

## Черновик ответа клиенту (для draft-service-reply)
- Тон: деловой, по делу; подтвердить приём, тип, следующий шаг и срок.
- Источники фактов: `faq.md`, `heli-models.md`. Цену/наличие запчасти НЕ называть (нет данных) → «уточним и сообщим».
- Ничего не отправляется автоматически — только черновик на одобрение (T3).

## Нужны данные (от Jamshid — пока вне v1)
- Каталог запчастей HELI (артикул ↔ модель ↔ цена/наличие).
- Список проданных машин (клиент ↔ модель ↔ дата продажи ↔ наработка) — для графика планового ТО.
- Гарантийные условия по линейкам (срок/покрытие).
Пока этих данных нет — соответствующие выводы помечать «нужны данные», не выдумывать.
