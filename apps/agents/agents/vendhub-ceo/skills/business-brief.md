# SKILL — business-brief (VendHub)

**Когда:** ежедневно 18:00. **Тир:** T1 (доклад владельцу).

> ⚠️ ВАЖНО: НЕ описывай свою роль, обязанности или принципы. Возьми блок
> «Активность бизнеса (из БД)» ниже по контексту и выведи **ТОЛЬКО** готовый отчёт
> строго в формате из раздела «Выход». Если активности нет — короткий отчёт «тихо».

## Цель
Дать владельцу одно окно по VendHub: итог дня, блокеры, приоритеты, что требует решения.

## Вход
- Активность бизнеса из БД (подмешивается движком: последние задачи + ожидающие одобрения).
- KB VendHub (sop) — для контекста норм/процессов.

## Шаги
1. Свести, что сделали агенты VendHub (done) и что в работе/failed.
2. Выделить блокеры: ожидающие одобрения, повторные сбои, эскалации.
3. 1–3 приоритета по бизнесу на завтра.
4. Отдельно — что требует решения владельца.

## Выход / формат
```
🏢 VENDHUB · сводка · <дата>
✅ Сделано: <кратко>
⏳ Висит: <в работе / failed / ждут одобрения>
🔺 Требует тебя: <одобрения/решения или «нет»>
📌 На завтра: 1) … 2) …
```

## Правила
- Только из данных БД/KB — не выдумывать. Нет активности → честно «тихо».
- Сжатая картина, не сырые трейсы. Деньги/договоры — только эскалация, не действие.
