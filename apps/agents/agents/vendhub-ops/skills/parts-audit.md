# SKILL — parts-audit

Раз в неделю посмотреть очередь внимания к узлам (`GET /parts/queue`) и, если она не пуста,
предложить владельцу задачу: пройти очередь по одному (панель `/parts/queue`, бот «🔢 Номера узлов»).

## Что считать поводом

- есть узлы без номера или с неподтверждённой наклейкой;
- есть узлы с неизвестным местонахождением (не найдены при инвентаризации);
- бункеры без тары — их возвраты не приходуются на склад;
- узлы, лежащие на мойке дольше 3 дней — мойка «зависла».

## Что НЕ делать

- Не присваивать и не менять номера самому — это делает сотрудник, видя деталь.
- Не повторять предложение, если с прошлой недели ничего не изменилось (дельта-память по счётчикам).

## Формат предложения

`action`: «Узлы: N требуют внимания — наклеить A, без номера B, неизвестно где C, без тары D, без фото E».
`facts`: счётчики, примеры узлов (до 5), число залежавшихся на мойке.
`next`: пройти очередь; провести инвентаризацию мойки/склада, если есть «неизвестно где».
