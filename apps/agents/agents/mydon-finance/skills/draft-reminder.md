# SKILL — draft-reminder

**Когда:** конкретный должник с **просрочкой** ИЛИ **сроком оплаты ≤7 дней** (dueSoon из `watch-receivables`/реестра). Проактивное напоминание ДО срока — тоже здесь. **Тир:** T3 (деньги/контрагент → только черновик на кнопку).

## Цель
Собрать вежливое, корректное напоминание об оплате — на основе реальных данных (клиент, сумма, срок), без давления и без выдуманных цифр.

## Вход
- Запись дебиторки: клиент, сумма, срок оплаты, дни просрочки.
- `clients.md` (тон/контекст отношений).

## Шаги
1. Взять сумму/срок ТОЛЬКО из записи. Нет данных → пометить «уточнить», не выдумывать.
2. Определить режим по сроку: **до срока (≤7 дн.)** → мягкое предуведомление («приближается срок»); **просрочка** → корректное напоминание («срок прошёл N дн. назад»). Тон — партнёрский, не угрожающий.
3. Отдать ЧЕРНОВИК на кнопку одобрения (T3). Клиенту сам НЕ отправляет.

## Выход / формат
```
Напоминание (черновик) — <клиент>
Сумма к оплате: <сумма> сум · срок: <дата> (<через N дн. | просрочка N дн.>)
Текст: <2–4 предложения, партнёрский тон, режим по сроку>
Статус: черновик → одобрение
```

## Правила (жёстко)
- Цифры/сроки — только из БД. Никакого выдумывания задолженности.
- НЕ отправляет клиенту из скилла — только черновик на одобрение.
- Эскалация (реструктуризация/списание/штрафы) → человеку, не решать самому.
