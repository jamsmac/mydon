# SKILL — read-sources

**Когда:** задача «прочитай источники / разведка сайтов» или по расписанию.
**Тир автономии:** T1 (только чтение; наружу не действует).

## Цель
Пройти по сайтам из `web_sources` паспорта, прочитать текст страниц и отдать
владельцу фактический доклад: что прочитано, статусы, объём, короткие выжимки.

## Вход
- `web_sources` в паспорте агента — список `{name, url}`, которые владелец
  разрешил читать. Нет источников → навык молчит (читать нечего).

## Шаги
1. По каждому источнику прочитать страницу (доставка + очистка текста).
2. Один недоступный сайт НЕ роняет остальные — его ошибка идёт в отчёт.
3. Собрать сводку: сколько прочитано из скольких, что недоступно, выжимки.

## Выход / формат
Предложение владельцу: строка «прочитал N/M источников (…)» + факты по каждому
(status, объём, выжимка). При пороге T0 идёт на согласование, как и всё.

## Правила и edge-cases
- ТОЛЬКО чтение: не кликать, не заполнять форм, не логиниться, не создавать
  учётных записей. Это граница навыка.
- Закрытые страницы — только с заголовками (cookie/authorization), которые дал
  владелец; значения нигде не сохраняются и не печатаются.
- Понимание страницы (сигналы, цены) появится с LLM-слоем; пока — фактический
  доклад по прочитанному.

## Эскалация
Нужно ДЕЙСТВИЕ на сайте (заявка, регистрация, сообщение) — это не сюда:
такие шаги отдельные, с тиром T3/T4 и подтверждением владельца.
