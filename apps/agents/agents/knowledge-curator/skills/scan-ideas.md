# SKILL — scan-ideas

**Когда:** еженедельно (cron) или по задаче «что нового в каналах идей».
**Тир автономии:** T2 (чтение публичного превью + запись дайджеста в заметку).

## Цель
Собрать из каналов владельца (`idea_channels`) свежие посты-фишки и отдать
дайджест «что перенять в MYDON»: список идей, ссылки, что недоступно.

## Вход
- `idea_channels` в паспорте — публичные каналы (напр. `promtjam`). Нет каналов
  → навык молчит (читать нечего).

## Шаги
1. По каждому каналу прочитать публичное превью `t.me/s/<канал>` (только чтение).
2. Разобрать посты: текст, ссылки, время. Медиа-посты без текста пропустить.
3. Собрать топ свежих постов (по номеру) в дайджест.
4. Дельта-память: если самый свежий пост не изменился с прошлого раза — молчать.

## Выход / формат
Предложение владельцу: «Идеи из каналов (…): N постов. Свежие: …» + факты
(каналы, топ идей с ссылками). При поднятом пороге исполнитель КОПИТ дайджест в
заметку Core (реестр знаний). При T0 — на согласование, как всё.

## Правила и edge-cases
- ТОЛЬКО чтение публичного превью: не постить, не подписываться, не писать в канал.
- Разбор идёт по стабильной разметке превью; сменят разметку — навык вернёт
  меньше постов или пустой список, но не упадёт.
- Понимание/оценку идей (годится ли фишка) добавит LLM-слой; пока — фактический
  дайджест со ссылками.

## Эскалация
Решение «внедрять фишку» — за владельцем (это approval), агент только приносит.
