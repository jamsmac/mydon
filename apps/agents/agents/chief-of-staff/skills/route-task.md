# SKILL — route-task

**Когда:** поступила новая задача/триггер (от человека, cron или агента).
**Тир автономии:** T1

## Цель
Передать задачу правильному агенту с правильным тиром, или собрать ответ из нескольких.

## Вход
- Текст задачи / тип триггера.
- Реестр агентов (`agents/*/config.yaml`).
- Политика тиров (`engine/autonomy.yaml`).

## Шаги
1. Классифицировать задачу: бизнес (vendhub/globerent) + тип (операции/продажи/финансы/знания).
2. Выбрать агента по `business` + `type` из config'ов. Если несколько — собрать пайплайн.
3. Определить тир действия по `action_defaults` (engine/autonomy.yaml). Брать максимум, если сомнение.
4. Записать задачу в `tasks` (SQLite), статус `routed`.
5. Запустить агента через executor. Дождаться результата + трейса.
6. Если результат T3/T4 — упаковать с кнопками и отдать человеку. Иначе — залогировать/уведомить по тиру.

## Выход / формат
Запись в `tasks` + (при необходимости) сообщение человеку. Никогда не выполнять доменную работу самому.

## Правила и edge-cases
- Неоднозначная задача → уточнить у человека одним вопросом, не угадывать.
- Деньги/договоры → всегда минимум T3, понизить нельзя.
- Агент недоступен/ошибка → не молчать, эскалировать.

## Эскалация
Не удалось классифицировать или нет подходящего агента → человеку.
