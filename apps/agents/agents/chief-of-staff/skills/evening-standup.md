# SKILL — evening-standup

**Когда:** cron 19:00 (Asia/Tashkent).
**Тир автономии:** T0 (отправить и залогировать).

## Цель
Одно сообщение в Telegram: итог дня по бизнесам + что переносится на завтра.

## Вход
- Задачи из SQLite за сегодня (статусы done/escalated/failed).
- Открытые одобрения (`approvals` со статусом pending).
- Последний отчёт `vendhub-ops` и открытые лиды/КП `globerent-sales`.

## Шаги
1. Посчитать выполненное за день: done-задачи по агентам.
2. Собрать «зависло»: escalated/failed + одобрения, ждущие реакции.
3. Выделить 1–3 пункта на завтра (перенос приоритетов + дедлайны).
4. Отрендерить по шаблону. Отправить. Записать трейс.

## Выход / формат
```
╔══════════════════════════════╗
║  MYDON · Вечер · <дата>      ║
╚══════════════════════════════╝
✅ Сделано: <N задач> (<агенты>)
⏳ Зависло: <escalated/failed + ждут одобрения N>
📌 На завтра
  1. ...
  2. ...
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

## Правила и edge-cases
- Пустой день — честно «тихо», не выдумывать активность.
- Ждущие одобрения подсветить отдельно — это блокеры.
- Числа из SQLite/KB, не из головы.

## Эскалация
Одобрение висит pending > суток или повторный failed по одному агенту → поднять отдельным пунктом.
