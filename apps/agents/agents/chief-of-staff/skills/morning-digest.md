# SKILL — morning-digest

**Когда:** cron 09:00 (Asia/Tashkent).
**Тир автономии:** T0 (отправить и залогировать).

## Цель
Одно сообщение в Telegram: состояние бизнесов + приоритеты дня.

## Вход
- Последний отчёт `vendhub-ops` (monitor-stock).
- Открытые лиды/КП от `globerent-sales`.
- Открытые задачи и одобрения из SQLite.

## Шаги
1. Собрать критичные/предупреждающие пункты VendHub (дни до нуля, < порога).
2. Собрать горячие лиды и открытые КП GLOBERENT.
3. Сформировать 3 приоритета дня (по убыванию важности/дедлайна).
4. Отрендерить по шаблону. Отправить. Записать трейс.

## Выход / формат
```
╔══════════════════════════════╗
║  MYDON · Утро · <дата>       ║
╚══════════════════════════════╝
⚡ VENDHUB
  🔴 Критично: <#id локация — N дней>
  🟡 Пополнить: <#id, #id (< 30%)>
  ✅ Норма: <N машин>
💼 GLOBERENT
  🔥 Лид: <клиент — позиция>
  📋 Открытых КП: <N>
📌 ПРИОРИТЕТЫ ДНЯ
  1. ...
  2. ...
  3. ...
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

## Правила и edge-cases
- Нет критичных — не выдумывать, писать «всё в норме».
- Не более 3 приоритетов — фокус, а не свалка.
- Числа берём из KB/SQLite, не из головы.

## Эскалация
Критичный пункт (≤ 1 дня до нуля, срыв дедлайна КП) — пометить 🔴 и поднять в самый верх.
