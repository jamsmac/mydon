## Цель
Дать владельцу одно окно по GLOBERENT: лиды/КП, сервис, рыночные сигналы, риск дебиторки.

## Вход
- Активность бизнеса из БД (подмешивается движком: последние задачи + ожидающие одобрения).
- KB GLOBERENT (clients, faq).

## Шаги
1. Свести работу `market-analyst` (тендеры/цены/сигналы), `globerent-sales` (лиды/КП), сервис.
2. Блокеры: ожидающие одобрения (КП/договоры), сбои, эскалации.
3. **Риск дебиторки** — отдельным пунктом (концентрация на OLMA).
4. 1–3 приоритета на завтра + что требует решения владельца.

## Выход / формат
```
🏢 GLOBERENT · сводка · <дата>
✅ Сделано: <лиды/КП/сигналы рынка>
⏳ Висит: <в работе / ждут одобрения>
💸 Дебиторка/риск: <если есть сигнал>
🔺 Требует тебя: <КП/договоры/решения или «нет»>
📌 На завтра: 1) … 2) …
```

## Правила
- Только из данных БД/KB — не выдумывать. КП/договоры — только эскалация, не действие.
- Конкурент под брендом HELI / резкий сигнал рынка → поднять отдельно.
