# Роутер · Личный контур — только владелец

**Домен в коде:** `personal`. **Доступ:** только владелец — гейт личного контура в агрегатах задач
(R-P5-7a, #255), personal-фильтр и owner-токен в боте (R-P5-8/9, #257; enforcement пока выключен по умолчанию).

## Агенты

Нет. Ни один агент не читает личный контур, если это не сказано явно в его паспорте и не пропущено
гейтом. Будущие виджеты календаря/почты на главной — только чтение (T0), только для владельца.

## Экраны CC

- `/domain/personal` (`PERSONAL_GROUPS`): **Каталог** — Недвижимость · Транспорт · Накопления · Договоры · Счета.
- Задачи направления — в `/tasks` с фильтром по домену (`lib/task-directions.ts`).

## Данные

- Те же универсальные таблицы Core (`entity`, `document`, `money_flow`, `task`) с доменом `personal`.
- Ничего из личного контура — в промпты агентов, отчёты и брифинги без явного разрешения.

## Референсы

- `apps/cc/src/lib/owner.ts`, `lib/core-owner.test.ts` — как определяется владелец.
- Спека `docs/superpowers/specs/2026-08-31-p5-web-identity-rbac-design.md` — web identity и owner-only RBAC.
