# session-log — handoff между сессиями

Один файл на сессию: `YYYY-MM-DD-<slug>.md`. Пишет `/calibrate` в конце сессии (или вручную).
Не журнал действий — **передача смены**: что нужно знать следующей сессии, чтобы не начинать с нуля.

## Шаблон

```markdown
# 2026-09-04 · <тема сессии>

## Активный контекст
Над чем работали, в каком состоянии (ветка, PR, что собрано, что нет).

## Сделано
- …

## Ожидает
- … (кого/чего ждём: решение владельца, CI, данные)

## Решения этой сессии
- … (с причиной; крупные — отдельным файлом в docs/decisions/ и строкой в memory/decisions.md)

## Исправления владельца → куда легли
- «…» → routers/vendhub.md / .claude/skills/… / memory/constraints.md

## Следующий шаг
Одно действие, с которого начать.
```

Правила: коротко; ссылки вместо пересказа; старше 30 дней — можно удалять, если всё перенесено в decisions/constraints.
