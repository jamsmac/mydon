# Активация агентов MYDON — runbook владельца

Все «умные» части агентов построены и покрыты тестами, но **спят по умолчанию**:
без ключей/шлюзов агенты работают детерминированно (смотрят Core, предлагают
дело, молчат когда повода нет). Этот файл — единственная точка правды: какие
тумблеры щёлкнуть, чтобы включить мозг, память и самоулучшение, и что каждый
включает.

Принцип безопасности сквозной: **агент ничего не делает сам** — он пишет событие
и создаёт запрос на согласование (HITL). Автономия по умолчанию `T0` (только
предлагает). LLM-шлюзы и embed-модель держать **только внутри Tailscale**.

## Два способа щёлкать тумблеры

- **Из панели** (`Система · Активация`) — не-секретные глобальные тумблеры
  (мозг/RAG/пауза/бюджет/автономия) хранятся в базе Core и **перекрывают `.env`**.
  Правки действуют без пересборки: агенты накладывают их при перечитке. Это
  рекомендуемый путь для владельца — с телефона, без доступа к серверу.
- **Через `.env`** — то же самое на уровне окружения (когда базы ещё нет или для
  первичной настройки). Приоритет: **база > env > дефолт**.
- **Секреты (API-ключи) — только `.env`.** В панели их принципиально нет
  (правило ТЗ). Для рекомендуемого пути подписки ключа и не требуется.

## Карта тумблеров (`.env`)

| Что включает | Переменная(ые) | Пусто (по умолчанию) | Задано → эффект |
|---|---|---|---|
| **Мозг на подписке** (Stage 0) | `LLM_PROVIDER=claude-cli` \| `codex-cli` \| `gemini-cli` | LLM-путь выключен, навыки детерминированы | Запускает CLI-харнесс на подписке, трат по токенам нет |
| **Мозг по HTTP** (метрируемо) | `LLM_BASE_URL` (OpenAI-совместимый) | — | Метрируемое API / AI-gateway; включать вместе с `AGENT_BILLING_MODE=metered` |
| **Семантическая память** (RAG, #6b) | `EMBED_BASE_URL` (+ `EMBED_MODEL`) | Память спит; остаётся дельта-память по сигнатуре | Дедуп идей по смыслу: не предлагать повторно уже разобранное |
| **Ингестор канала** | `ideaChannels` в паспорте `knowledge-curator` (уже `promtjam`) | Навык молчит | Читает публичное превью канала, приносит дайджест «что перенять» |
| **Расписания** | `AGENTS_SCHEDULES_PAUSED=0` | `1` — расписания на паузе | Агенты работают по графику из паспортов |
| **Бюджет** | `AGENT_BILLING_MODE` (`subscription`\|`metered`), `AGENT_DAILY_BUDGET_USD`, `AGENT_GLOBAL_BUDGET_USD` | `subscription`, $5/$5 (потолок спит) | `metered` → потолок активен, при превышении — `on_exceeded` |
| **Потолок автономии** | `AGENT_AUTONOMY_MAX` | `T0` — только предлагает | Выше → часть действий без согласования (осторожно) |

## Сценарий 1 — включить мозг на подписке (без трат по токенам)

Рекомендуемый путь: платим за подписку CLI, не за токены.

1. Установить и авторизовать нужный CLI в окружении агентов (`claude` / `codex`
   / `gemini`).
2. В `.env`:
   ```
   LLM_PROVIDER=claude-cli        # или codex-cli / gemini-cli
   # при нестандартной версии CLI можно переопределить команду:
   # LLM_CLI_CMD=claude
   # LLM_CLI_BASE_ARGS=-p
   # LLM_CLI_MODEL_FLAG=--model
   ```
3. (Опц.) Резервные модели для ротации: `LLM_FALLBACK_MODELS=...`. Позже поверх
   можно поставить claudexor — он ротирует несколько харнессов по квотам (план в
   `docs/` про Hetzner-мозг).

> **Важно про контейнер.** `mydon-agents` запускается из образа `deploy/Dockerfile`,
> и подписочного CLI (`claude`/`codex`/`gemini`) там нет по умолчанию. Для пути
> подписки его нужно доустановить в образ (или примонтировать) **и авторизовать**
> внутри контейнера — иначе харнесс не запустится. Более контейнер-дружелюбный
> вариант — HTTP-путь (`LLM_BASE_URL` на gateway) внутри Tailscale. Сами
> переменные до процесса уже долетают: `deploy/docker-compose.yml` прокидывает
> все тумблеры в сервис `mydon-agents`.

Что оживает: навык `assess-ideas` (оценка фишек канала моделью) и петля coach
(EVAL/PROPOSE). Без шлюза оба честно спят.

## Сценарий 2 — включить семантическую память (RAG)

1. Поднять OpenAI-совместимый `/embeddings` (локальная модель в Tailscale или
   облачный endpoint).
2. В `.env`:
   ```
   EMBED_BASE_URL=http://<tailscale-host>:<port>
   EMBED_MODEL=text-embedding-3-small     # или своя
   # EMBED_API_KEY=...                     # если endpoint требует
   ```

Что оживает: `assess-ideas` перед оценкой **вспоминает похожие уже разобранные
идеи** и просит модель не повторять их, а после — запоминает разобранные посты.
Хранение — в журнале Core (переживает рестарт). Векторы разной длины/битые
считаются несовпадением (0) — память не «галлюцинирует» совпадения.

Граница инъекций сохранена: пересказ прошлых постов — тоже внешний текст, идёт в
**недоверенный** блок под маркером, доверенная инструкция лишь просит не
повторять.

## Сценарий 3 — самоулучшение (coach) и применение правок

Петля: coach судит последнее действие агента по рубрике → при «improve»
предлагает правку `SKILL.md` (SEARCH/REPLACE diff) → владелец одобряет →
правка ложится git-коммитом.

- **Судья** (`coach-review`) оживает вместе с мозгом (Сценарий 1). `coach-agent`
  уже `active`, расписание еженедельное. Правка НЕ применяется сама — приходит
  предложением в очередь (diff в фактах). Безопасность 1–2 по рубрике → эскалация
  без правки. Судья не судит сам себя.
- **Применение** одобренной правки — отдельная деливерейт-операция **там, где
  есть репо и git** (обслуживающий скрипт / CI / машина владельца), НЕ в
  эфемерном проде:
  ```
  pnpm --filter @mydon/agents coach:apply -- <агент>/skills/<навык>.md <файл-с-diff>
  ```
  Инварианты (все проверяются): path-guard (только `<агент>/skills/<навык>.md`
  известного агента), каждый блок diff указывает на тот же файл, SEARCH
  символ-в-символ, коммит только при успехе, git-откат. Правится **только**
  `SKILL.md` — никогда код/config/ROLE/факты.

## Проверка «включилось ли»

При старте `apps/agents` печатает позы (posture) LLM-пути, бюджета и coach —
видно, что активно, а что спит. Если тумблер задан, но навык молчит, порядок
проверки: (1) `ideaChannels`/`webSources` в паспорте не пусты, (2) канал/сайт
реально читается, (3) `AGENTS_SCHEDULES_PAUSED=0`, (4) для мозга — CLI
авторизован в окружении.

Ничего не задано → это не поломка: агенты работают детерминированно, очередь
остаётся сигналом, а не лентой.
