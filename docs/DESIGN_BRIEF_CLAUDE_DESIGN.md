# ТЗ для Claude Design — панель MYDON

Скопируй всё, что ниже линии, в Claude Design одним сообщением.
Результат (готовый HTML-прототип) пришли обратно — перенесу его в живую панель.

---

Спроектируй интерфейс **MYDON** — командного центра владельца нескольких бизнесов.
Один пользователь — владелец, не программист, город Ташкент. Язык интерфейса — русский.
Пользуется поровну с телефона и с компьютера: сначала прорисуй мобильную версию, потом широкую.

## Фирменный стиль (обязателен, не менять)

- Фон: `#0A1628` (тёмно-синий). Поверхности карточек: `#0F1E33`, приподнятые: `#152640`, линии: `#1E3350`.
- Акцент: `#1A6BFF` (синий) — активные вкладки, кнопки, ссылки.
- Текст: `#E8ECF2`, второстепенный: `#8494A8`, приглушённый: `#5A6B80`.
- `#FF6B1A` (оранжевый) — СТРОГО только для «требует решения владельца» и просрочек. Больше нигде.
- Успех: `#2BD9A0`, ошибка: `#FF4D5E`.
- Шрифты: **Syne** (заголовки), **Manrope** (текст), **IBM Plex Mono** (все цифры, суммы, коды, серийники — с табличными цифрами `tabular-nums`).
- Скругления 10–12px, тонкие линии вместо теней, минимум анимации.

## Структура приложения

Слева на компьютере — узкое боковое меню, на телефоне — нижняя панель (максимум 5 пунктов):
**Главное · Задачи · Решения · Команда · Агенты** (+ на компьютере: Реестр, Журнал, направления GLOBERENT и VendHub).
В правом нижнем углу всех экранов — плавающая кнопка ✦: раскрывается чат с помощником.

## Экраны

### 1. Рабочее место направления (главный экран для проработки!)

Направление = предприятие. Пример — VendHub (сеть кофейных автоматов).
Первая страница — **Дашборд**, выше — ряд вкладок, у групп есть подвкладки:

- **Дашборд**: плитки «должны нам / должны мы / просрочено / открытых задач»
  (цифры крупные, mono; просрочено > 0 — оранжевым), ниже «что заведено» со ссылками.
- **Каталог** → подвкладки: Товары ×34 · Аппараты ×15 · Компоненты · Ингредиенты · Рецепты · Расходники.
- **Справочники** → Классификатор ×2 · НДС ×2 · ИКПУ ×20 · Упаковка ×19 · Штрих-коды ×19 · Поставщики.
- **Отчёты** → Журнал продаж · Инкассация · Сроки годности · Себестоимость.
- **Команда** и **Задачи** — люди и задачи этого направления.

Подвкладки без данных видны, но приглушены с подписью «появится после сбора».

### 2. Список записей (внутри вкладки)

Плотная таблица-книга, строка ~44px, вся строка кликабельна:

| Название | Код (mono, приглушён) | Цена (mono, выровнена вправо) |
|---|---|---|
| Americano | 08476001003000000 | 20 000 сум |
| Red Bull CAN 0,33 | 9002490206000 | 35 000 сум |

У аппаратов вместо цены — серийник: `3266181f0000`. На телефоне колонка кода прячется.
34 строки должны читаться без утомления: цены сравниваются глазами по правому краю.

### 3. Карточка записи

Сначала ЧТЕНИЕ, потом правка. Сверху — сетка полей-паспорта
(метка мелким верхним регистром, значение крупно, коды — mono):

ЦЕНА 20 000 сум · ИКПУ 08476001003000000 · УПАКОВКА 1503411 · КАТЕГОРИЯ Кофейные напитки

У автомата: СЕРИЙНИК, ТОЧКА + кнопка «Открыть на карте».
Кнопка «Изменить» превращает паспорт в форму (те же поля), «+ Поле» добавляет своё.

### 4. Задачи

Группы по срочности: «Горит» (оранжевая метка) → «Сегодня» → «На неделе» → «Позже».
Строка: название, исполнитель (человек или агент), срок словами («завтра», «через 3 дня»).
Карточка задачи: описание, переписка, закрытие с обязательным отчётом,
после «сделано» — оценка владельца: ⭐ Отлично / Принято / ↩ Переделать.

### 5. Команда

Люди сгруппированы по направлениям (GLOBERENT, VendHub, Личный контур).
Строка: имя, роль, «висит 3 · в срок 80% · отлично ×2 · переделки ×1», метка «в Telegram».
Карточка сотрудника: профиль, блок «Качество работы», список «в работе» и «сделано» с оценками.

### 6. Решения (согласования)

Карточки с оранжевой рамкой: «Завести 34 товара VendHub из страницы ПО» + кто просит (агент) +
три кнопки: ✅ Одобрить · ❌ Отклонить · ❓ Уточнить. После нажатия карточка показывает итог.

### 7. Плавающий помощник

Кнопка ✦ → панель чата поверх экрана: вопрос свободным текстом
(«что мы решали по поставщику кофе?»), ответ с опорой на память и цифры системы.

## Принципы

- Оранжевый = «нужно моё решение». Увидел оранжевое — надо нажать.
- Все цифры — IBM Plex Mono с выравниванием, суммы с пробелами: «20 000 сум».
- Пустой экран всегда говорит, что сделать: «Пришли страницу ПО — вкладка оживёт».
- Не рисуй лишних графиков и декора: это рабочий инструмент на каждый день.

## Что нужно на выходе

Работающий HTML-прототип (как ты умеешь): мобильный и широкий вид,
экраны 1–3 обязательно с переключением вкладок и открытием карточки,
экраны 4–7 — хотя бы по одному состоянию.
