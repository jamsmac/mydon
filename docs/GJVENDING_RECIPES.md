# Рецепты кофейных напитков из ПО gjvending — как забрать оптом

> Кабинет `https://www.gjvending.net` (Happy Workers). **Только чтение**: ничего
> в их системе не меняем — слово владельца 20.08.2026.

## Точка входа

Логин с капчей проходит владелец сам, в своём Chrome. Дальше всё берётся
запросами из вкладки этого же кабинета (сессия в куках).

## Эндпоинты (все GET/POST, только чтение)

| Что | Запрос |
|---|---|
| Токен | `GET /index/getToken` → `{code:1, data:"<uuid>"}` |
| Товары шаблона | `POST /goods/getGoodsListByModelId?modelId=<id>&token=<T>&language=ru&rows=90` |
| **Все рецепты шаблона разом** | `GET /model/binded?model_id=<id>` → `{goods:{<goodsId>:[{...рецепт...}]}}` |
| Один рецепт | `GET /modelCoffee/detail?taste_id=<t>&model_id=<m>&goods_id=<g>` |
| Пропорции | `GET /modelCoffee/getProportion?modelId=<id>` |

`/model/binded` — самый быстрый путь: один запрос отдаёт рецепты ВСЕХ вкусов
шаблона. `/api/model/getMaterialDetailByTasteId` из их JS отвечает медленно
(pending) — не использовать.

## Шаблоны (Coffee Pattern Management, 19 шт, рабочих 6)

| id | Имя | Примечание |
|---|---|---|
| 7098 | VAMAR Log | основной |
| 5876 | new | основной |
| 7135 | KIUT New | рецептура совпадает с `new` |
| 5992 | Matcha new | |
| 7136 | KIUT Matcha New | |
| 7099 | Matcha test | |

По рецептурам шаблоны сложились в **5 различных наборов**: `new` = `KIUT New`,
остальные — каждый свой. Цены отличаются между шаблонами, рецептура — реже.

## Поля рецепта

`x1..x8` — дозаторы (г): x1 молоко, x4 сахар, x5 шоколад, x7 кофе (зерно).
`cs1..cs4` — вода/наполнение по каналам (мл). `soak_water`/`soak_time` — вода и
время предсмачивания (мл/с). `xm_water` — вода заваривания (мл). `ice_num` — лёд (г).
`cost1..cost3` — себестоимость по трём уровням закупочных цен.
`price` — цена продажи в этом шаблоне.

**Важно (слово владельца):** у одного товара несколько ОДНОВРЕМЕННО действующих
рецептов — по вкусам («с сахаром», «с ванильным сиропом», «без сахара»), и у
каждого своя себестоимость. Плюс у рецептов есть история версий.
