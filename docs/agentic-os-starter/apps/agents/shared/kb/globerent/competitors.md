## Как ведём
- Новый игрок из `scan-uz-market` → добавить строку (статус active) + дата/источник.
- Цены из `scan-prices` → колонка позиции; демпинг считается vs наш `pricelist.md` (когда заполнен).
- Ушёл с рынка → статус `gone` + дата (не удалять — история).

*Базлайн из мастер-промпта исследования. Реальные цены/доли/контакты — наполняют сканы и Jamshid.*
