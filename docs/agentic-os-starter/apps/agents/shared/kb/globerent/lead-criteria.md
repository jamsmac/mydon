# GLOBERENT — критерии квалификации лидов (hot/warm/cold)

> Используют `globerent-sales` (`hunt-leads`, `qualify-lead`). Это **правила**, а не данные клиентов.

## Сигналы (каждый 0–2 балла)
| Сигнал | 0 | 1 | 2 |
|---|---|---|---|
| **Фит модели** (FD/FG/CPD/G, см. heli-models) | нет | частично | точно |
| **Объём** (единиц техники) | неясно | одна | несколько+ |
| **Срочность** (срок/дедлайн/тендер) | нет | в этом квартале | < 30 дней |
| **Бюджет/платёжеспособность** | нет признаков | косвенно | явно |
| **Доступ к ЛПР** | нет | есть канал | прямой контакт |

## Маппинг нашей сетки на BANT (общий язык с продажами)

Наша 5-факторная сетка (выше) выражается через BANT — для единого словаря, не замена:

| BANT | Наш сигнал | Что подтверждаем |
|---|---|---|
| **B**udget (бюджет) | Бюджет/платёжеспособность | есть ли деньги/финансирование под закупку |
| **A**uthority (ЛПР) | Доступ к ЛПР | выходим ли на принимающего решение |
| **N**eed (потребность) | Фит модели + Объём | реальная потребность под линейку HELI и её масштаб |
| **T**iming (сроки) | Срочность | когда закупка: квартал / <30 дней / тендер-дедлайн |

## Два вопроса MEDDIC (углубление для hot/warm)
- **Metrics:** какую метрику клиент улучшает закупкой? (тонн/час перевалки, простой склада, стоимость аренды текущего парка, ремонт старой техники). Считаемая выгода → сильнее КП.
- **Decision process:** как и кем принимается решение — тендер / директор / совет; этапы и сроки согласования; кто подписывает. Знаем процесс → не теряем сделку на согласовании.

> ICP/скрипты SaaS-доноров не копировать — у нас B2B-техника, не подписка. Берём только структуру BANT/MEDDIC.

## Классы и следующий шаг
- **hot** — score ≥ 8 и есть (срочность ИЛИ бюджет) → `draft-quote` (КП → кнопка T3).
- **warm** — score 4–7 → прогрев: уточнить потребность/ЛПР, добавить в базу.
- **cold** — score < 4 или нет фита/ЛПР → в базу, периодическое касание.

## Где искать сигналы (`hunt-leads`)
- Новости: новые склады/заводы/распред-центры/фулфилмент/СЭЗ/индустриальные зоны (Ташкент → ЦА).
- Маркетплейсы/объявления (OLX и аналоги): покупка/аренда/замена погрузочной техники.
- Логистика/3PL, холодные склады, порты/сухие порты, крупная стройка.
- Истечение лизинга/аренды парка техники.
- **Граница:** госзакупки/тендеры ведёт `market-analyst` (`scan-tenders`) — не дублировать.

## Риск-правила
- Концентрация на одном клиенте — флаг (ср. риск OLMA ~79% дебиторки в `clients.md`).
- Цена — только из `pricelist.md`; нет позиции → эскалация, не выдумывать.

*Правила квалификации. Реальные клиенты/цены — в `clients.md` / `pricelist.md` (заполняет Jamshid).*
