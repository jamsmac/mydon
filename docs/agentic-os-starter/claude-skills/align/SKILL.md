# /align — scope до усилия

Правило владельца: сначала факты, потом одно решение без вариантов. Вопросы — только те, ответ на которые
меняет, что будет сделано. Всё, что можно узнать из роутеров, кода или `memory/`, — узнать самому.

## Когда обязателен

- Задача затрагивает деньги, договоры, публикации от имени владельца, права доступа (тиры T3–T4).
- Меняется структура навигации, ключи вкладок, схема данных или паспорт агента.
- Личный контур (`personal`) или данные реальных клиентов.
- Формулировка допускает два разных результата.

## Шаги

1. Перечислить **допущения**, с которыми можно начать без вопросов (их больше, чем вопросов).
2. Сформулировать **не более 3 вопросов**, каждый с вариантом ответа по умолчанию:
   «Если не ответите — сделаю так: …». Владелец может ответить одним словом или промолчать.
3. Показать **границы**: что войдёт, что не войдёт (out of scope), критерий готовности одной фразой.
4. Получив ответы — записать итог в 5 строк и начинать. Если решение принципиальное — файл в `docs/decisions/`
   с причиной и строка в `memory/decisions.md`.

## Формат

```
Понял задачу так: …
Допущения (делаю без вопросов): 1. … 2. … 3. …
Вопросы (ответ по умолчанию в скобках):
  1. … (по умолчанию: …)
  2. … (по умолчанию: …)
Не войдёт: …
Готово, когда: …
```

## Чего не делать

- Не задавать вопросы, ответ на которые есть в `routers/`, `memory/constraints.md`, `docs/decisions/`.
- Не предлагать «варианты А/Б/В» вместо решения по умолчанию.
- Не начинать код до ответа, если вопрос касается денег, автономии или личного контура.
