# Примитивы оболочки (`apps/cc/src/app/globals.css`)

Истина — CSS и эталонные страницы; здесь — что уже есть и когда брать. Прежде чем писать новый класс,
найди примитив ниже. Внутренние элементы (`.tt`, `.lab`, …) описаны как вложенные селекторы своего примитива.

## Каркас страницы

| Класс | Назначение | Эталон |
|---|---|---|
| `.app`, `.hdr` (+ `.logo`, `.sub`, `.sp`) | обёртка приложения и шапка 64px | `app/layout.tsx` |
| `.side` (+ `.gl` — заголовок группы, `.bdg2` — счётчик) | сайдбар, ≥ 900px | `components/nav.tsx` |
| `.tabbar` (+ `.bdg` — точка-счётчик) | нижняя панель телефона, только `MAIN` | `components/nav.tsx` |
| `.page-head` → `.h1` + `.lead` | заголовок страницы и строка «что это · когда обновлено» | `app/mydon/page.tsx` |
| `.back` | ссылка «← Все …» над заголовком карточки | `app/agents/[name]/page.tsx` |
| `.crumbs` | крошки (карточка 360) | `components/card-tabs.tsx` |
| `.tabs`, `.subtabs` | липкие вкладки направления (`--tabs-h`) и подвкладки | `app/domain/[domain]` |
| `.eyebrow` | малая uppercase-метка над блоком (в командном центре — метка раздела) | — |
| `.section-title` | заголовок секции списка («В работе», «Что делал») | `app/agents/page.tsx` |
| `.sect` → `.sect-h` (+ `.h2`) | секция с заголовком и действиями справа | `app/mydon/page.tsx` |

## Контейнеры и списки

| Класс | Назначение |
|---|---|
| `.card` (мод. `.hot` — тревожная карточка с полосой `--hot`) | карточка: `--surf`, `1px --line`, `--r`, 16px |
| `.rows` → `.row` (мод. `.rowlink` — вся строка ссылка) → `.t` (`b` + `small`) + `.pill` / `.when` | список записей одной высоты |
| `.trow` (мод. `.hot`) → `.tb` (`.tt` заголовок, `.tm` мета с `.who` и аватаром `.av.ag` ✦) + `.due` | строка задачи/решения с действием справа |
| `.tiles` → `.tile` (мод. `.is-hot`, `.zero`) → `.lab` · `.v` · `.foot` (`.mk` маркер) | плитки-вопросы владельца: подпись · число · «нужно внимание / спокойно» |
| `.wgrid` → `.wt` → `.wl` · `.wv` · `.go` | плитки-переходы (направления, ссылки) |
| `.grid`, `.g2`, `.g4` | простая сетка карточек |
| `.kv` | пары «ключ — значение» в карточке |
| `.table-scroll` | таблица с горизонтальной прокруткой внутри (страница не скроллится вбок) |
| `.stats` | строка мелких моно-показателей под записью |

## Состояния и сигналы

| Класс | Назначение |
|---|---|
| `.empty` (`b` + текст) | пустое состояние: заголовок + одно предложение, **что сделать** |
| `.notice` | предупреждающий блок на `--hot-soft` |
| `.warn`, `.warn-text`, `.err-msg`, `.err-text`, `.ok-msg`, `.ok-text` | текст состояния |
| `.chip` (мод. `.h` — тревожный), `.chips` | чип-статус/фильтр («требует решения · 3») |
| `.pill` (мод. `.ok`) | круглый статус в строке («работает / выключен») |
| `.tag`, `.tags`, `.tag-*` | теги карточки |
| `.toast` | всплывающее подтверждение внизу |
| `.hint`, `.muted` | подсказка / приглушённый текст |
| `CoreDown` (`components/core-down.tsx`) | экран «Core недоступен» с деталью — вместо падения страницы |

| `.iconbtn` | кнопка-иконка в шапке (`components/header-actions.tsx`) |

| `.search`, `.pager` | поиск и пагинация списков |
| `.drawer` (+ `.drawer-h/.drawer-t/.drawer-b`) | выезжающая панель |
| `.cmdk*` | палитра команд ⌘K (`components/command-palette.tsx`) |
| `.fab*`, `.chat*` | плавающий помощник (`components/floating-chat.tsx`, `chat.tsx`) |

## Иконки и шрифтовые утилиты

`Ic` из `components/icons.tsx` (имена: `home`, `tasks`, `dec`, `team`, `jour`, `agents`, `biz`, `box`, `reg`);
`.mono` / `.num` — моно с табличными цифрами; `.h1`, `.h2` — размеры заголовков.

## Доменные примитивы (не переиспользовать вне направления)

`.mc-*` (карточка автомата 360), `.mb-*` / `.bnk-*` / `.bunker*` (бункеры и кофе), `.mnu-*` (меню автомата),
`.llm-*` (настройки и мониторинг LLM на `/system`), `.j*` (журнал), `.raw*` (сырые отчёты), `.qcard*` / `.qgrid`
(очередь утверждения), `.leaflet-*` (карта).

## Чего нет — и что добавить при первой потребности (в `globals.css`, рядом с родственными)

`.panel.console` (жёсткая рамка + смещённый контур), `.led` (статус агента), `.av8` (пиксельный аватар) —
см. `rules.md` §4. Добавлять с тестом на контраст и в обе ветки темы, если появятся новые цвета (не должны).
