# Токены MYDON (`apps/cc/src/app/globals.css`)

Истина — в CSS; здесь карта имён и ролей для быстрого выбора. Числа контраста — к холсту `--bg` своей темы.
На токены сидят ~430 классов: имена не менять.

## Холст и поверхности

| Токен | Светлая | Тёмная | Роль |
|---|---|---|---|
| `--bg` | `#f4f4ee` | `#111712` | холст (тёплый белый с оливковой нотой / почти чёрный) |
| `--surf` | `#ffffff` | `#18211a` | карточка |
| `--surf-2` | `#fbfaf5` | `#202b22` | приподнятое, ховер |
| `--field` | `#ffffff` | `#18211a` | поле ввода — отдельно от холста |
| `--line` | `#dce0d7` | `#2c3324` | декоративные разделители (не текст) |
| `--line-soft` | `#e8ebe3` | `#232a1d` | внутренние разделители |
| `--line-strong` | `#7c8b7a` | `#6b7a5b` | границы контролов — 3,26:1 |
| `--shadow` | `0 14px 44px rgba(33,43,34,.1)` | `… rgba(0,0,0,.55)` | тень карточек (в консольной грамматике не используется) |
| `--overlay` | `rgba(23,32,25,.34)` | `rgba(0,0,0,.6)` | подложка модалок |

## Шрифты, радиусы, размеры

| Токен | Значение | Роль |
|---|---|---|
| `--fh` | Golos Text 600/700 (`--font-display`) | заголовки `h1–h3`, `letter-spacing: -0.01em` |
| `--fu` | Golos Text 400/500/600 (`--font-body`) | текст, 15px / 1.45 |
| `--fm` | IBM Plex Mono 400/500/600 (`--font-mono`) | данные, цифры (`.mono`, `.num` — табличные цифры) |
| `--r` / `--r-s` | `12px` / `10px` | радиус карточек / контролов |
| `--bar` | `64px` | высота шапки |
| `--tabs-h` | `55px` | липкая панель вкладок направления (офсет для липких панелей под ней) |

## Устаревшие алиасы (не использовать в новом коде)

`--navy`→`--bg`, `--surface`→`--surf`, `--raised`→`--surf-2`, `--blue`→`--accent`, `--white`→`--tx`,
`--steel`→`--tx-2`, `--steel-dim`→`--tx-3`, `--orange`→`--hot`, `--red`→`--err`.

## Цвет строки браузера

`themeColor` в `layout.tsx`: светлая `#f4f4ee`, тёмная `#111712` — менять вместе с `--bg`.
