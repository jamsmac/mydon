# Правила дизайна MYDON

Источник каждого правила — комментарии в `apps/cc/src/app/globals.css`, `components/nav.tsx`, `layout.tsx`
и `docs/decisions/2026-08-22-navigaciya-i-gamma.md`. Здесь — выжимка.

## 1. Оранжевый — лицо продукта (решение 29.07.2026)

**«Увидел оранжевое — надо нажать.»** Две глубины, роли разводит форма:
- `--accent` (яркий) — **только сплошная заливка** и только с тёмными чернилами поверх: активная вкладка,
  основная кнопка, логотип. Значит «ты здесь / главное действие». **Белого текста на оранжевом нет нигде** (2,85:1).
- `--hot` (глубокий) — всё, что тоньше заливки: текст, иконка, полоска тревоги, мягкая подложка `--hot-soft`.
  Значит «сюда посмотри». Оранжевый текстом на светлом — только `--accent-tx`/`--hot`.
- Оранжевого мало. Если на экране больше одной заливки — экран неправильный.

## 2. Три уровня текста, не четыре

`--tx` (15:1) · `--tx-2` (7:1) · `--tx-3` (4,7:1). Уровни раздвинуты по контрасту, а не по оттенку.
Четвёртого серого нет — он не пройдёт 4,5:1 на светлом холсте.

## 3. Пороги контраста

Текст ≥ 4,5:1 к своему фону; нетекстовые элементы (границы контролов, иконки состояний) ≥ 3:1.
Каждое значение токена уже проверено — поэтому цвета не смешивать и не осветлять «на глаз».
Тёмная тема — не инверсия: там яркий оранжевый читается текстом (7:1), обе глубины светлее, а не темнее.

## 4. Грамматика командного центра (агентский слой)

Для `/mydon`, `/agents`, `/crons`, `/flows`, `/skills`, `/brain`, `/artifacts`:
- тёмная тема по умолчанию (`data-theme="dark"` на этих маршрутах); бизнес-экраны остаются светлыми;
- метки разделов — существующий `.eyebrow` (10,5px, 700, uppercase, трекинг 0.13em, `--tx-3`); для цифровых
  меток добавлять `.mono`. Новый класс `.lbl` не заводить;
- панель `.panel.console` (**новый класс**, добавить в `globals.css` рядом с `.card`): жёсткая рамка
  `1px solid var(--line-strong)` + смещённый контур 4 px (`box-shadow: 4px 4px 0 var(--line)`), без размытой
  тени; радиус `--r-s`;
- статусы агентов — `.led` (**новый**): квадрат 8×8 + слово; `idle` → `--ok`, `working` → `--accent-tx`,
  `blocked` → `--err`. Именно `--accent-tx`, а не `--accent`: §1 отдаёт `--accent` сплошным заливкам с
  тёмными чернилами, а лампа — мелкая нетекстовая метка, и заливка ею нарушила бы «оранжевого мало»;
- аватар агента — `.av8` (**новый**): детерминированный 8×8 SVG от имени, цвет всегда `--agent` (у активного тоже:
  состояние говорит лампа, а не аватар);
  новые классы — в обе ветки темы, если используют цвета вне токенов (не должны);
- цифры — `--fm` с табличными цифрами (`.num`); пиксельный display-шрифт — только для цифр и только после
  проверки контраста; **кириллица — всегда Golos Text**;
- фон — точечная сетка через `components/bg/` (уже есть звёздное небо для тёмной темы — не дублировать эффекты).

Эталон грамматики — `/skills` (05.09.2026, спека skills-deck-cron-llm).

## 5. Структура экрана

- Заголовок страницы — `.page-head` (`.h1` + `.lead` одной строкой: что это и когда обновлено).
- **Плитка = вопрос владельца, клик = подробный ответ.** Число без вопроса — не плитка.
- **Пустой экран всегда говорит, что сделать** (`.empty`: жирная строка + одно предложение).
- Ошибка Core не роняет экран: `CoreDown` с деталью; счётчики в меню деградируют до 0.
- Не глубже двух уровней навигации в поле зрения. Таббар телефона — только сквозные пункты (`MAIN`),
  сайдбар скрыт ниже 900 px; вход в рабочие места с телефона — блок «Направления» на главной.
- Активный пункт — один: побеждает самый длинный совпавший путь (`aria-current="page"`).

## 6. Язык и типографика

- Русский в UI. Подписи вкладок — русские (Р-2: латиница заглавными читается как приём ради приёма).
- Тир — словами, не буквой: «только спрашивает / предлагает, решаешь ты / мелкое — сам / многое — сам / почти всё сам».
- Golos Text (заголовки 600/700, текст 400/500/600), IBM Plex Mono для данных; файлы локальные в `apps/cc/src/fonts/`.
- Формы времени и чисел — через `lib/format.ts` (`when`, суммы, склонения).

## 7. Формы

`onSubmit` + `event.preventDefault()` + `new FormData(event.currentTarget)` → server action в `startTransition`;
`res.ok` → сброс ошибки и `router.refresh()`; отказ → `setError(res.message)`, **поля сохраняют ввод**.
Тест обязан проверять сохранение ввода при ошибке (`customs-rates.test.tsx`).

## 8. Тема

Тёмная тема объявлена дважды намеренно: `@media (prefers-color-scheme: dark)` для системной настройки и
`:root[data-theme="dark"]` для явного выбора. `themeColor` в `layout.tsx` следует теме. Новые токены —
в обе ветки, иначе тема «протечёт».
